# Snake

A classic Snake game written in Python using pygame.

## What it does

You control a snake on a grid. Eat the green apple to grow longer. The game doesn't end — just keep eating and watch your score climb.

## Stack

- Python 3
- pygame

## Setup

```bash
pip install pygame
python main.py
```

## Controls

| Key | Action     |
|-----|------------|
| W   | Move up    |
| S   | Move down  |
| A   | Move left  |
| D   | Move right |
